# Diseño de reportes exportables

PDFKit genera informe anual e informe por institución; ExcelJS genera la matriz completa de un eje. Los endpoints validan parámetros y devuelven descargas con fecha y usuario generador. PDFs incluyen encabezado con escudo de Bolivia; Excel conserva columnas y metas del Cuadro B. React usa file-saver para descargar desde dashboard y vista por eje.
