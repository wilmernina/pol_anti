# Vista por Eje Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mostrar ficha, matriz y resumen de un eje con datos reales.

**Architecture:** Rutas SQL de detalle devuelven ficha, matriz, avance y reportes; React renderiza componentes de tabla expandible y descarga CSV.

**Tech Stack:** Express, pg, React, TypeScript, Vite, Tailwind, Vitest, Supertest.

**Spec:** `docs/superpowers/specs/2026-09-22-vista-eje-design.md`

## Global Constraints

- SQL parametrizado y JSON `{ success, data, error }`.
- CSV UTF-8 compatible con Excel.
- Sin datos simulados; botón de reporte deshabilitado hasta Parte 17.

## Review Focus

- Código fuera de 1–9 devuelve 400.
- Eje inexistente devuelve 404.
- Meta NULL muestra `—`.
- Error de red permite reintentar.
- Tabla se desplaza horizontalmente en móvil.
